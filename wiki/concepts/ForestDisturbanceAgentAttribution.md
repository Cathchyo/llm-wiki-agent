# 森林扰动原因归因

森林扰动原因归因是在发现森林出现异常后，进一步判断异常主要由什么因素造成，而不只输出“是否发生了扰动”。本文将目标类别设为野火、砍伐、虫害或干旱等胁迫，以及非扰动异常。（来源：[[liaopdf]]）

## 核心流程

1. 用 [[SCCD]] 从 HLS 时间序列中圈出偏离正常轨迹的森林像元或斑块。
2. 从已有的跨地区扰动档案中挑选与中国目标瓦片植被和地形相似的样本，训练临时模型生成初步原因分类图。
3. 由专家查看候选斑块的时间序列和前后影像，保留高把握的野火、砍伐、胁迫和非扰动样本，形成中国本地训练样本。
4. 根据连续异常次数建立多个阶段模型；新影像到来时，调用对应阶段模型，结合光谱变化幅度、方向、持续时间、季节和扰动前状态进行分类。
5. 每周更新原因地图，合并相邻斑块并过滤小面积或明显噪声结果。

## 与监督式扰动监测的关系

[[SupervisedLandDisturbanceMonitoring]] 主要解决“这个异常是否是真实扰动”；森林扰动原因归因进一步解决“真实扰动属于哪一类原因”。两者都可以使用历史样本和分阶段模型，但评价目标不同，不能直接混用各自的延迟和准确率。

## 与 SCCD 的关系

[[SCCD]]（本文中写作 S-CCD）是异常生成和时间序列更新模块，不负责单独判断野火或砍伐。原因归因模型位于其后，利用 S-CCD 产生的异常及其光谱—时间特征进行多类别分类；[[CCDC]] 是相关连续变化检测方法的基础谱系。

## 边界

外部样本只能作为参考，不能直接替代中国本地核验；不同地区的树种、气候、经营方式和扰动强度会改变光谱轨迹。胁迫类信号尤其容易与季节变化或噪声混淆，光学数据还会受到云层和有效观测不足的影响。原因分类也不等于损失评估或责任认定。
