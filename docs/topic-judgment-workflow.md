# 公众号选题判断：最小工作流

这个工作流只做一件事：把每次选题变成一次可以学习的判断。

## 选题时

对 Agent 说：

```text
记录选题：为什么普通人需要了解 AI Agent
```

Agent 会创建发布前记录，只判断：是否愿意点开、是否愿意分享收藏、
是否愿意关注。

## 拿到数据后

对 Agent 说：

```text
记录结果：20260807-01
```

然后粘贴公众号后台数据或截图。Agent 会保存结果、计算可计算的比例，
并和发布前判断对照。

## 积累五篇后

对 Agent 说：

```text
复盘选题
```

Agent 会找出反复正确、反复错误和证据不足的判断，并只提出下一批文章
要验证的一个假设。

## 原则

- 先预测，后看数据。
- 发布前记录不回改，结果单独保存。
- 阅读量只作为背景，不单独证明判断正确。
- 一篇文章不形成规律。
- 缺少数据就写 `unknown`，不要猜。
